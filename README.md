# Багодром

Интерактивный тренажёр для начинающих тестировщиков: 47 задач в 10 модулях.

Открыть: **https://tacitcoast.github.io/qa-lab/**

## Что внутри

| Модуль | О чём |
|---|---|
| 01 | Валидация на фронте — живая форма регистрации с дефектами против ТЗ |
| 02 | Валидация на бэкенде — конструктор запросов к API мимо формы |
| 03 | HTTP-коды и REST — 2xx/4xx/5xx, идемпотентность, PUT против PATCH |
| 04 | Текст ошибки и подсказки — что показывать пользователю, а что нельзя никогда |
| 05 | DevTools — Network с waterfall, Console, Application |
| 06 | Локализация багов — фронт, бэк, данные или окружение |
| 07 | Тест-дизайн — классы эквивалентности, границы, попарное тестирование |
| 08 | Защита данных — подмена cookie, правка JWT, IDOR, журнал аудита |
| 09 | Авторизация — Basic, cookie-сессия, Bearer с обменом refresh, API-key |
| 10 | Транспорты — REST, GraphQL, gRPC, WebSocket: когда какой и почему |

В восемнадцати задачах есть рабочие стенды:

- форма регистрации с дефектами против ТЗ;
- симулятор DevTools: Network с waterfall и Timing, Console, Application;
- конструктор HTTP-запросов к симулированному API;
- приложение с подменой cookie и правкой JWT;
- вход четырьмя способами с панелью «что уходит в заголовках»;
- GraphQL с настоящим разбором запроса: выбор полей, ошибки валидации,
  частичные ответы и `200 OK` с непустым `errors`;
- вызовы gRPC-методов из `.proto` с кодами `0/3/5/7/12/14/16`;
- WebSocket: handshake `101`, поток сообщений, ping/pong, обрыв и потеря сообщений.

Задача засчитывается, когда выполнена цель на стенде **и** отвечены вопросы —
сначала сломать руками, потом объяснить.

## Как это работает

Один самодостаточный HTML-файл: ни бэкенда, ни сборки, ни внешних зависимостей,
кроме шрифтов Google (без интернета подставятся системные). Все «серверы»,
«девтулзы» и ответы API — симуляция внутри страницы.

Прогресс хранится в `localStorage` браузера студента и никуда не отправляется.
Кнопка «сброс» в шапке очищает его.

Открывается с телефона, тема светлая или тёмная по настройке системы.

## Локально

```
python3 -m http.server 8000
```
и открыть `http://localhost:8000/` — или просто открыть `index.html` двойным кликом
(в этом случае некоторые браузеры не дадут сохранять прогресс между заходами).
